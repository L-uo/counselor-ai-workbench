## 主要功能

### 学生工作
- 学生档案管理
- 学生成长事件记录
- 旷课、奖励、困难认定等信息管理
- 学生工作时间线

### 日程与任务
- 日 / 周 / 月日程
- 工作任务与节点
- 到期提醒
- 催办辅助
- 今日工作台

### 教学
- 我的课程
- 学期课表
- 单双周课程
- 课程自动同步日程

### 数据工具
- Excel 批量导入学生名单
- Excel 批量导入课表
- 数据统计与 Excel 导出
- 本地数据备份与恢复

---

## 数据与隐私

工作台的学生、日程、任务、课程等业务数据默认保存在本机浏览器的 IndexedDB 中。

Excel 文件在本机解析，不会因为批量导入功能自动上传至云端。

建议定期使用“数据备份与恢复”功能下载本地备份。

涉及学生个人信息时，请按照所在单位的数据管理要求使用本软件。
