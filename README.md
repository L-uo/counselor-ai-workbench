# 这是什么？

高校辅导员、班主任和学生工作教师每天会处理大量看起来“不复杂”，但非常碎片化的事务：

- 学生信息散落在 Excel、微信、OA 等不同地方
- 临时找学生时，不知道他现在是否在上课
- 不同学院、部门导出的 Excel 表头格式不同
- 学校制度临时要用时，很难快速找到
- OA、教务、学工、财务等系统入口分散
- 任务、日程、材料截止时间容易遗漏
- 通知、谈话提纲、工作总结经常需要重复整理
- 学生工作资料需要定期备份和迁移

**辅导员 AI 工作台** 希望把这些高频事务集中到一个本地桌面工作台中。

它不是学校管理系统的替代品。

更准确地说，它是：

> **辅导员、班主任自己的本地个人工作台。**

# 核心特点

## 1. 本地数据优先

学生档案、任务、日程、课程、课表、学校制度、常用模板等核心业务数据默认保存在当前 Windows 电脑本地。

普通业务数据主要使用本地 IndexedDB 数据库存储。

Excel / CSV 文件也在当前设备本地解析。

---

## 2. 无需注册软件账号

软件安装后即可使用。

当前版本：

- 不要求注册软件账号
- 不要求登录云端账户
- 不强制联网
- 不强制使用 AI

没有配置 API Key 时，绝大多数本地功能仍然可以正常使用。

# 一、工作台首页

首页用于快速查看当天的工作情况。

可以集中查看：

- 当前日期
- 学年学期
- 教学周
- 今日日程
- 今日待办
- 今日教学安排
- 近期任务
- 工作提醒
- 快捷操作入口

适合作为每天打开软件后的第一站。

---

# 二、学生档案

学生档案用于统一保存和管理学生信息。

可以记录：

- 学号
- 姓名
- 班级
- 学院
- 专业
- 年级
- 性别
- 手机号
- 宿舍
- 其他学生工作所需字段

同时支持为学生建立成长纪事和事件时间线。

例如：

- 谈心谈话
- 请假
- 学业问题
- 宿舍问题
- 家校沟通
- 获奖
- 特殊事项
- 持续跟进记录

以后打开学生详情页，可以连续查看过去的工作记录。

---

# 三、学生查课

这是 v1.1.0 的重要功能之一。

辅导员或班主任可以通过：

- 姓名
- 学号
- 班级

快速查找学生。

系统根据：

- 班级课表
- 学生个人课程调整
- 当前学期
- 当前教学周
- 学校节次时间

推算学生当前课程状态。

可以查看：

- 当前是否处于上课时间
- 当前课程
- 当前节次
- 预计上课地点
- 任课教师
- 下一节课程
- 今日课表
- 本周完整课表

> 注意：
>
> “预计上课地点”根据已经录入的课表进行推算。
>
> 本软件不进行 GPS、Wi-Fi 或其他形式的实时学生定位。

---

## 班级统一课表

同一个班级通常只需要维护一份课表。

班级内学生可以继承对应班级课表。

这样不需要给几十名学生分别保存完全相同的课程信息。

---

## 学生个人课程调整

考虑到学生可能存在：

- 加修
- 重修
- 辅修
- 选修
- 免修
- 调课
- 特殊教学安排

系统支持为单个学生建立个人课程调整。

个人课程调整只影响该学生。

---

## 课程冲突提醒

如果个人课程和班级课程发生时间冲突，系统会提示异常，方便人工检查。

下载软件提供的标准模板。

按照模板填写后直接导入。

- 教务系统导出的学生名单
- 学院学生名单
